# DSH-TASK-V1：公考错题本（iPad 网页版）

下达：文轩经 DSH云端官 · 2026-11-09
执行方：dsh（本 bot 只布置与半小时抽查，不写业务代码）

## 目标
做一份**仅文轩自己用**的公考错题本，**iPad Safari 网页版**即可打开使用。科目：**事业单位 D 类 · 职测 + 综应**一起做。

## 已拍板需求
1. 使用对象：仅自己用（不做多人产品）
2. 科目：职测 + 综应同步做
3. 录入方式：拍照 + 手动输入都要；并支持上传文件、截图等扩充方式
4. 自动分析错题原因：知识点/考点缺失、审题/方法出错、粗心/时间/心态等都要
5. 思维导图复盘：两种都要——上传导图对照错题自动标薄弱点；自己标注再按导图提醒复盘
6. 联网策略：平时离线可看错题/记笔记；分析时再联网
7. 错题进来后：马上看原因分析、整理进章节/考点本、过几天再复习——都会用到
8. 形态：第一版 = iPad 网页版（Safari），不做 App Store 原生
9. 数据存哪：对话未最终拍板；默认先本机/浏览器存储为主，分析走云端 API，暂不做强账号体系

## 最小可交结果（做到即停，不扩范围）
- 可在本机/云端启动的网页，iPad Safari 可用的基础布局
- 错题录入：拍照/相册/文件/截图/手动文字（能落库即可）
- 单题自动分析（职测、综应字段可区分）输出：知识点、方法、粗心等标签 + 简短原因
- 导图上传后与错题对照标薄弱点；支持自标 + 复盘提醒（简单即可）
- 离线可读已有错题与笔记；联网时再触发分析
- 基础章节/考点整理 + 简单复习列表
- 验收说明：如何启动、如何在 iPad Safari 打开、账号/密钥若需要如何配置
- 0 元原则：不擅自付费；不删用户数据
